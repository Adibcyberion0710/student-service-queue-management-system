
# Student Service Queue Management System

A university student service queue management system developed using C and a Doubly Linked List.

## Course Information
- Course: Data Structure
- Course Code: CSE 207
- Department: Computer Science and Engineering
- University: East West University

## Project Description
This project manages student service requests using a Doubly Linked List.

Each student receives a unique token number. Requests are normally served in arrival order (FIFO).

## Features
- Add student requests
- Generate token numbers automatically
- Serve students
- Search requests by token number
- Cancel requests
- Display the waiting queue

## Data Structure
Doubly Linked List
